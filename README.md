# Информатика в приложении к отрасли

Лабораторные работы по дисциплине **«Информатика в приложении к отрасли»**.

## О дисциплине

Дисциплина посвящена практическому применению современных инструментов 
разработки: системе контроля версий Git, виртуальным окружениям Python, 
тестированию ПО, непрерывной интеграции, веб-разработке и контейнеризации.

## Содержание

### Git и Python venv

Создание виртуального окружения в PyCharm, установка модулей через pip, 
создание репозитория на GitHub, клонирование через GitKraken, работа 
с ветками и pull-request'ами.

Реализованные программы:
- вычисление чисел Фибоначчи с визуализацией (NumPy, Matplotlib)
- алгоритм Евклида (НОД)
- решето Эратосфена
- сортировка пузырьком с выбором направления
- поиск общих элементов в N списках
- unit-тесты через `unittest` и `pytest`

Стек: Python, NumPy, Matplotlib, Git, GitKraken, PyCharm.

### Тестирование программного обеспечения

Составление классов эквивалентности и граничных значений для формы 
регистрации, оформление чек-листов и баг-репортов.

Реализация библиотеки функций с unit-тестами:
- числа Фибоначчи
- сортировка пузырьком
- калькулятор

Стек: Python, pytest, техники тест-дизайна.

### GitHub Actions

Построение процесса непрерывной интеграции (CI) для Python-проекта 
на GitHub Actions.

- настройка workflow `.github/workflows/ci.yml`
- автоматический запуск тестов при `push` и `pull_request`
- генерация HTML-отчёта через `pytest-html`
- загрузка артефактов

Стек: Python, pytest, GitHub Actions, YAML.

### Разработка веб-сервиса

Разработка REST API для хранения текстовых заметок.

Реализованные методы:
- создание заметки
- чтение заметки по id
- получение информации о заметке (дата создания, обновления)
- обновление заметки
- удаление заметки
- вывод списка заметок

Стек: Python, FastAPI, Pydantic, Uvicorn.

### Работа с API веб-сервисов

Построение запросов к GitHub API через Postman: вывод списка репозиториев 
организации и текущего пользователя, создание и удаление репозиториев. 
Реализация консольного приложения с аналогичным функционалом.

Стек: Python, Postman, GitHub REST API.

### Docker

Создание Docker-образов и контейнеров.

- сборка и запуск Java-приложения (Hello World) в контейнере
- разработка Flask-приложения и его запуск через Docker
- работа с Dockerfile, портами, томами
- базовые команды: `docker build`, `docker run`, `docker stop`, `docker rm`, 
  `docker images`

Стек: Docker, Java, Python, Flask.

## Стек

Python, FastAPI, Flask, NumPy, Matplotlib, pytest, Java, Docker, 
GitHub Actions, Postman, Git, GitHub, GitKraken.
